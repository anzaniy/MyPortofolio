## Overview

The **Booking Service** module in the Honda Kita system receives booking data from the mobile app. The API bridges the data users enter in the app with the company system, so bookings are recorded on the dealer side right away.

## Background

The mobile app needed a stable communication path with the main system when customers booked a service. Previously, data fetching was inefficient and several related web pages needed fixes.

## My Role

- Developed the booking service API so data from the mobile app connects to the system.
- Designed and fixed the web system pages that were broken.
- Fixed API functions that returned errors.
- Optimized the database so queries run more efficiently.

## Scope of Work

- **API integration**: adapting endpoints to the mobile app's needs.
- **Interface fixes**: repairing web pages whose layout was off.
- **Query optimization**: reducing repeated data calls and adjusting query structure.
- **Testing**: checking API responses and data consistency after the changes.
