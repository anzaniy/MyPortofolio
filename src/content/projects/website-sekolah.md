## Ringkasan

Website profil sekolah untuk SMA Al Kautsar yang menjadi pusat informasi resmi sekolah. Proyek ini dikerjakan selama masa magang sebagai Web Developer Intern, mulai dari pengumpulan konten hingga implementasi halaman.

## Latar Belakang

Informasi sekolah seperti profil, sejarah, data alumni, dan dokumentasi kegiatan masih tersebar dan belum terpusat. Sekolah membutuhkan satu website yang bisa diakses publik dan mudah diperbarui oleh pengelola.

## Peran Saya

- Mendesain dan mengembangkan website sekolah menggunakan **CodeIgniter 3**.
- Mengumpulkan data alumni, sejarah sekolah, dan dokumentasi kegiatan.
- Menyusun struktur halaman agar informasi mudah ditemukan.
- Melakukan penyesuaian tampilan agar nyaman dibaca di desktop maupun ponsel.

## Fitur

- **Profil sekolah** — informasi umum, visi, dan misi.
- **Data alumni** — daftar alumni sebagai bagian dari arsip sekolah.
- **Sejarah sekolah** — perjalanan dan perkembangan sekolah.
- **Dokumentasi kegiatan** — galeri foto dan catatan aktivitas sekolah.

## Teknologi

| Bagian | Teknologi |
| --- | --- |
| Bahasa | PHP |
| Framework | CodeIgniter 3 |
| Arsitektur | MVC |

## Alur Pengerjaan

1. **Pengumpulan kebutuhan** — wawancara dan pengumpulan data dari pihak sekolah.
2. **Perancangan struktur** — menentukan halaman dan alur navigasi.
3. **Implementasi** — membangun halaman dengan pola MVC CodeIgniter 3.
4. **Pengujian** — memeriksa tampilan dan fungsi dasar sebelum diserahkan.
