## Ringkasan

Halaman ini masih berupa **placeholder** untuk project pribadi. Nantinya bagian ini berisi project yang kamu kerjakan sendiri di luar pekerjaan, misalnya eksperimen, tugas kuliah yang dikembangkan lagi, atau aplikasi kecil.

## Rencana Isi

Setiap project pribadi akan ditulis dengan format yang sama seperti Work Project:

- Ringkasan project
- Latar belakang dan tujuan
- Peran dan teknologi yang dipakai
- Dokumentasi proses
- Screenshot hasil

## Cara Mengganti

Bagian ini akan diganti dengan project pertama. Cukup tambahkan satu file baru di `src/content/projects/` dengan `kind: individual`, lalu hapus file placeholder ini.
