## Ringkasan

Modul **Booking Service** pada sistem Honda Kita yang menerima data booking dari aplikasi mobile. API berfungsi menjembatani data yang dimasukkan pengguna di aplikasi dengan sistem perusahaan, sehingga booking langsung tercatat di sisi dealer.

## Latar Belakang

Aplikasi mobile membutuhkan jalur komunikasi yang stabil dengan sistem utama saat pelanggan membuat booking service. Sebelumnya, proses pemanggilan data kurang efisien dan beberapa tampilan web terkait perlu diperbaiki.

## Peran Saya

- Mengembangkan API booking service agar data dari aplikasi mobile tersambung ke sistem.
- Mendesain dan memperbaiki tampilan sistem web yang bermasalah.
- Memperbaiki fungsi API yang mengalami galat.
- Mengoptimalkan database agar pemanggilan query lebih efisien.

## Cakupan Pekerjaan

- **Integrasi API**: menyesuaikan endpoint dengan kebutuhan aplikasi mobile.
- **Perbaikan antarmuka**: memperbaiki halaman web yang tampilannya tidak sesuai.
- **Optimasi query**: mengurangi pemanggilan data yang berulang dan menyesuaikan struktur query.
- **Pengujian**: memeriksa respons API dan konsistensi data setelah perubahan.
